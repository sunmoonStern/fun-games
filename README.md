# まなびじま

小学校低学年向けの、遊びながら学べるブラウザゲームです。

- **くくの しま**：九九の れんしゅう と てすと。全部の だんを ★3 にすると マスターチャレンジ、クリアで しょうじょう
- **えいごの しま**：どうぶつ・たべもの・いろ・かず の たんごちょう と てすと（はつおん つき）
- **キーボードの しま**：ホームポジションから ローマじ入力までの タイピング れんしゅう
- **ロボットの しま**：やじるしブロックを ならべて ロボットを うごかす プログラミング

ビルド不要の 1 ファイル（`index.html`）で動きます。★や記録はブラウザの localStorage に保存されます。
