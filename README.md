# まなびの あそびば

小学校低学年向けの、遊びながら学べるブラウザゲーム集です。

| パス | ゲーム | 内容 |
|---|---|---|
| `/` | ポータル | 2つのゲームへの入り口 |
| `/manabijima/` | まなびじま | 九九（れんしゅう・てすと・マスター賞状）、えいご（たんごちょう・てすと）、タイピング、矢印ブロックのプログラミング |
| `/robocode/` | ロボコード | ブロックを並べるか、エディタに `right 3` や `repeat … end` を打ち込んでロボットを動かす、全10ステージのプログラミングゲーム（ブロック／コードはタブで切り替え） |

ビルド不要の静的 HTML だけで動きます。★や記録はブラウザの localStorage に保存されます。

## コントリビューション

感想・提案・バグ報告・コードの改善、どれも歓迎します。

- **Issue**：バグや「こんな問題・ステージがほしい」などのアイデアは [Issues](https://github.com/sunmoonStern/fun-games/issues) へどうぞ。
- **Pull Request**：小さな修正でも大歓迎です。大きな変更は、先に Issue で相談してもらえると助かります。
- **メール**：GitHub を使わない方は code-for-future-moms@ymail.ne.jp まで。

### 手元で動かす

ビルドはありません。`index.html` をブラウザで開くか、ローカルサーバーを立てて確認してください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

### 変更するときのお願い

- 各ゲームは HTML 1ファイル（＋必要な画像・SVG）で完結させ、ビルドや外部ライブラリは増やさない方針です。
- 対象は小学校低学年です。画面の文言はひらがな中心で、ことばの区切りに空白を入れています。
- スマホ幅（360px 前後）でも崩れないか確認してください。
