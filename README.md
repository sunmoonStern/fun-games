# まなびの あそびば

小学校低学年向けの、遊びながら学べるブラウザゲーム集です。

| パス | ゲーム | 内容 |
|---|---|---|
| `/` | ポータル | 2つのゲームへの入り口 |
| `/manabijima/` | まなびじま | 九九（れんしゅう・てすと・マスター賞状）、漢字（かんじの しま →下の行）、えいご（たんごちょう・てすと）、タイピング、矢印ブロックのプログラミング |
| `/manabijima/kanji/` | かんじの しま（まなびじまの島のひとつ） | 小学1〜6年生の漢字1026字（最初に学年を選ぶ）。書き順アニメーション（おてほん）・なぞり書き・見ないで書く練習と、文を読んで漢字を書くテスト（書き順・向きも判定） |
| `/robocode/` | ロボコード | ブロックを並べるか、エディタに `right 3` や `repeat … end` を打ち込んでロボットを動かす、全10ステージのプログラミングゲーム（ブロック／コードはタブで切り替え） |

ビルド不要の静的 HTML だけで動きます。★や記録はブラウザの localStorage に保存されます。

## 使っているデータ

- `/manabijima/kanji/` の書き順データは [KanjiVG](https://kanjivg.tagaini.net/)（© Ulrich Apel, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)）をもとに、ストロークの座標だけを取り出して `manabijima/kanji/data/g1.js`〜`g6.js`（学年ごと。選んだ学年だけ読み込みます）に入れています。このデータ部分は CC BY-SA 3.0 に従います。
- 学年の割り当て（2020年度からの学年別漢字配当表）と、読みの確認には [KANJIDIC2](https://www.edrdg.org/wiki/index.php/KANJIDIC_Project)（© EDRDG, CC BY-SA 4.0）を使いました。

### 手元で動かす

ビルドはありません。`index.html` をブラウザで開くか、ローカルサーバーを立てて確認してください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

### 変更するときのお願い

- 各ゲームは HTML 1ファイル（＋必要な画像・SVG）で完結させ、ビルドや外部ライブラリは増やさない方針です（かんじの しまは書き順データが大きいので、学年ごとの `manabijima/kanji/data/g*.js` に分けています）。
- 対象は小学校低学年です。画面の文言はひらがな中心で、ことばの区切りに空白を入れています。
- スマホ幅（360px 前後）でも崩れないか確認してください。
