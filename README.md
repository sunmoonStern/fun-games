# まなびの あそびば

小学校低学年向けの、遊びながら学べるブラウザゲーム集です。

| パス | ゲーム | 内容 |
|---|---|---|
| `/` | ポータル | 2つのゲームへの入り口 |
| `/manabijima/` | まなびじま | 九九（れんしゅう・てすと・マスター賞状）、えいご（たんごちょう・てすと）、タイピング、矢印ブロックのプログラミング |
| `/robocode/` | ロボコード | エディタに `right 3` や `repeat … end` を打ち込んでロボットを動かす、全10ステージのプログラミングゲーム |

ビルド不要の静的 HTML だけで動きます。★や記録はブラウザの localStorage に保存されます。
